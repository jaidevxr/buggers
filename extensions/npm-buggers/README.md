# buggers

Official CLI and Developer Utilities for **Buggers** — Automated Pull Request Code Review, OWASP SAST Flaw Detection & Bug Triage.

- **Platform:** [https://buggers.dev](https://buggers.dev)
- **VS Code Extension:** [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=buggers.buggers-vscode)
- **Documentation:** [https://buggers.dev/docs](https://buggers.dev/docs)

## Quick Start

Run instantly without installation:

```bash
npx buggers scan .
```

Or install globally:

```bash
npm install -g buggers
buggers --help
```
